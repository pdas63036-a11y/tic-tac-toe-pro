# tic-tac-toe-pro
A modern and fully interactive Tic-Tac-Toe web application developed with HTML, CSS, and JavaScript. This project includes advanced features such as AI opponent, animated 3D UI effects, dynamic winning line visualization, interactive sound system, player name customization, and an automatic scoreboard for tracking game results
